# Specfold discipline

Convention usage follows humanymous Specfold patterns by **cite**, not copy.
See `.spec/sot/conventions-inherit.sot.md` and `C:\workspaces\humanymous\AGENTS.md`.

## Before changing governed code or specs

1. `spec context <path>` (or read the owning SoT).
2. Prefer updating `.spec/` over folklore in chat.
3. `spec check` before considering docs/spec work done.

## AGENTS.md is a router

Root `AGENTS.md` points at SoTs, rules, and skills. It MUST NOT become a second normative product SoT (`.spec/sot/agent-governance.sot.md`).

## Assets

When editing `.agents/**`, keep `spec.toml` `[[assets]]` in sync so `spec assets` / rule A1–A2 stay honest.
