# M26 — Shared-index N-way (Phase Si)

## Goal

Unlock and claim **shared-index N-way** writers coordinating one `$GIT_DIR/index` under product leases + documented Git `index.lock`, without rewriting M23 L3 worktree/ref-shard and without substituting M24/G22/G24 CELIR receipts.

Unlock authority: [[adr:root/20261110074000]].

## Claim set

| ID | Surface | Primary docs | Gate | Crate surface |
|----|---------|--------------|------|---------------|
| FW-SHARED-IDX | N writers → one shared index via `index:shared` lease + `index.lock` | [gitformat-index](https://git-scm.com/docs/gitformat-index), [api-lockfile](https://git-scm.com/docs/api-lockfile) | **G34** | `arks-lease` shared-index apply + `arks-index` lock write |

## Ordered work

1. **SoT unlock** — ADR supersession; residual FW-SHARED-IDX; lease SoTs; roadmap M26; interop G34; clean-room SoT; matrix + compose stub.
2. **Inner module** — `arks-lease` shared-index coordinator: exclusive `index:shared` grant → `arks-index` `write_path` (`index.lock` O_CREAT\|O_EXCL → rename) → release. Lease ≠ skip locks.
3. **Host advisory** — ≥2 concurrent writers prove serialize-under-lease + both entries land; held-lock refuse; second lease holder `AlreadyHeld`.
4. **Clean-room G34** — sole-runner Docker; evidence for product Verified. Host green alone is **not** Verified.

## Out of scope

- Substituting **M24 / G22 / G24** as shared-index proof.
- CELIR ObjectStore; inventing index format bytes; zero `gix` breach.
- Replacing M23 worktree/ref-shard as the L3 default claim.
- Skipping `index.lock` because a lease is held.

## Exit

| Honesty | Requirement |
|---------|-------------|
| **Claimed (SoT unlock)** | ADR + this plan + SoT/residual amend + `spec check` |
| **Host advisory** | 2-writer (or N) shared-index path green on host |
| **Verified** | Docker **G34** PASS + evidence receipt |

M26 Done (product Verified) = G34 Claimed. Interim honesty may stay **Claimed (SoT unlock) / Verified pending G34**.
