# M11 — Git server role (Phase Sv) — **production-server exit**

## Goal

Deliver **arks as a Git server** for the claimed subset: stock Git (and arks-as-client) can **clone / fetch / push** against an arks-hosted repository over claimed transports, with capability-safe advertise/refuse and clean-room **G15**. This is the **production-server** bar — **not** required for CLI-parity production (**M9**) and **not** a forge product.

## Dual-bar reminder

| Bar | Milestone | Meaning |
|-----|-----------|---------|
| **CLI-parity production** | **M9** | Client: same `.git` + CLI symmetry + alias-ready + remote **client** |
| **Production-server** | **M11** | Server: upload-pack / receive-pack (+ claimed transports) verified vs stock Git peer |
| Lease capability | **M10** | Default product leases (+ optional high-concurrency); independent of M11 — MAY run alongside after M9 |

## In scope / crates

| Artifact | Role |
|----------|------|
| `arks-protocol` (extend) | Server-side session helpers for pack protocol / v2 as claimed; no invented caps |
| `crates/arks-server` (Ring 6) | Transport bindings: smart HTTP service paths; SSH command-mode wrappers when claimed; optional `git://` daemon when claimed |
| CLI Wave **Sv** | `arks upload-pack`, `arks receive-pack`; optional `arks http-backend` / `arks daemon` equivalents when claimed ([[sot:root/cli-surface]]) |
| Auth (high level) | Documented HTTP Basic / reverse-proxy patterns; SSH key / `git-shell`-class restriction when claimed — no forge OAuth / GitHub App **as server** |
| Honesty | Public narrative claims only the shipped server subset; no forge UX |

Catalog: [[research:root/20261108071916]], [[research:root/20261108071859]]. Normative scope: [[sot:root/remote-host-compatibility-surface]].

## Out of scope

- Forge UX (web UI, PR merge API, Checks, Issues, GitHub App **as** arks server).
- Host product APIs (remote-host scope **(B)**).
- Raising **M9** to require server; calling M11 “CLI-parity production.”
- CELIR; inventing protocol capabilities; dumb-HTTP-only as the sole claimed server path without smart HTTP (unless SoT amendment).
- LFS / GUI exclusions; lease exposure over the wire (until lease SoT explicitly claims it).

## Depends on

**M9** exit by default (production-server after CLI-parity client production). Engineering MAY start after **M6** (client remotes + protocol proven) with an explicit [[sot:root/program-roadmap]] amendment; marketing / “production-server” claims still require **M11** exit + **G15**.

**M10** is **not** a prerequisite — M10 and M11 MAY proceed in parallel after M9.

## Exit gates

| Gate | Clean-room | Advisory |
|------|------------|----------|
| **G15** `git-server` | Authoritative: stock `git` clone/fetch/push against arks server for claimed transports | Host experiments |
| G5 / G7 regression | Protocol + client remotes stay green | Host |
| G14 regression | CLI-parity production must not regress | Host |

## Ordered work items

1. **Design** — Close transport claim matrix (smart HTTP required for production-server; SSH / `git://` / dumb HTTP as explicit MAY claims); auth surface table; refuse matrix for unimplemented caps; server-side hook honor for claimed receive-pack path.
2. **Scaffold** — `arks-server` crate; Wave Sv CLI stubs that refuse until implemented.
3. **Implement** — upload-pack path first (fetch/clone), then receive-pack (push + report-status); smart HTTP binding; SSH command invocation when claimed.
4. **Verify** — **G15** in clean-room; public-surface honesty (production-server only with receipts).

## Open questions

**Closed** (M11 production-server residual refuse — [[evidence:root/20261108231300]]; normative: [[sot:root/arks-server]]):

| Question | Resolution |
|----------|------------|
| First-ship transports beyond smart HTTP | **Smart HTTP only** for production-server. SSH / `git://` / dumb HTTP **refuse-close** until SoT amendment. |
| `arks http-backend` vs library-only CGI | **Separate Wave Sv CLI entry** (`arks http-backend`) plus `arks serve-http` listener — both smart HTTP; shipped in G15. |
| Server-side hook subset | **None honored** — refuse-unimplemented on receive-pack; no `.git/hooks/*` execution until explicitly claimed. |
| Auth beyond loopback | **No product auth server**; G15 loopback unauthenticated OK. TLS + HTTP Basic / reverse-proxy = **ops pattern only**. |
| Protocol v2 | **Refuse-close / not advertised** on the wire for first ship. |
