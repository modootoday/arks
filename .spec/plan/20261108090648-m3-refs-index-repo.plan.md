# M3 — Refs + index + repo (Phase R)

## Goal

Ref store (files / packed-refs as claimed), HEAD/symref, index read/write, and repo layout discovery; persistence through the store facade; honor **L0** Git locks.

## In scope / crates

| Artifact | Role |
|----------|------|
| `crates/arks-refs` | Refnames, loose/packed refs, HEAD/symref; L0 locks |
| `crates/arks-index` | Index file read/write for claimed versions |
| `crates/arks-repo` | `GIT_DIR` / layout discovery; compose store + refs |

## Out of scope

- Product lease API (L1+) — M7 only.
- Full G3 index-**commit** round-trip (requires Wave L `commit` — **M5**).
- Pack/protocol product claims (M4); CLI porcelain (M5).

## Depends on

**M2** exit (object persistence through facade).

## Exit gates

| Gate | Clean-room | Advisory |
|------|------------|----------|
| **G2** refs-roundtrip | Authoritative when harness exists | Host |
| Index r/w portion toward **G3** | Index fixtures vs stock Git | Host |
| L0 lock behavior | Documented + tested when harness exists | Host |

## Ordered work items

1. **Design** — Claimed ref/index subset from research; L0 lock citations only (no invented lock dialect).
2. **Scaffold** — refs / index / repo crates.
3. **Implement** — refs (+ locks) → index → repo compose.
4. **Verify** — G2; index r/w parity; do **not** mark full G3 until M5.

## Open questions

- Packed-refs write policy: **closed for M3** — **read-only** packed-refs; updates write loose overrides ([[sot:root/arks-refs]]). Rewrite deferred.
- Reftable: deferred unless explicitly claimed later.
