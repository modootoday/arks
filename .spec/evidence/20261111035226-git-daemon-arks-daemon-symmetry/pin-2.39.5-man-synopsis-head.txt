.SH "NAME"
git-daemon - A really simple server for Git repositories
.SH "SYNOPSIS"
.sp
.nf
git daemon [--verbose] [--syslog] [--export-all]
             [--timeout=<n>] [--init-timeout=<n>] [--max-connections=<n>]
             [--strict-paths] [--base-path=<path>] [--base-path-relaxed]
             [--user-path | --user-path=<path>]
             [--interpolated-path=<pathtemplate>]
             [--reuseaddr] [--detach] [--pid-file=<file>]

.sp
.SH "DESCRIPTION"
.sp
A really simple TCP Git daemon that normally listens on port "DEFAULT_GIT_PORT" aka 9418. It waits for a connection asking for a service, and will serve that service if it is enabled.
.sp
It verifies that the directory has the magic file "git-daemon-export-ok", and it will refuse to export any Git directory that hasn\(cqt explicitly been marked for export this way (unless the --export-all parameter is specified). If you pass some directory paths as git daemon arguments, the offers are limited to repositories within those directories.
.sp
By default, only upload-pack service is enabled, which serves git fetch-pack and git ls-remote clients, which are invoked from git fetch, git pull, and git clone.
.sp
This is ideally suited for read-only updates, i.e., pulling from Git repositories.
.sp
An upload-archive also exists to serve git archive.
.SH "OPTIONS"
.PP
--strict-paths
.RS 4
