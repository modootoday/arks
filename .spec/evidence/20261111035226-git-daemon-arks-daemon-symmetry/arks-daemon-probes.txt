
==== daemon --help ====
arks daemon — git:// TCP daemon (Wave Sv2 / M25)

Usage:
  arks daemon [--listen ADDR] [--export-all] [--enable=receive-pack] <base-path>

Requires git-daemon-export-ok in each repo unless --export-all.
