# Git index format

## Question

Which `.git/index` versions and extensions must GIR read/write to share working trees with stock Git?

## Method

Primary: gitformat-index; design notes sparse-index, sparse-checkout, racy-git; layout path for `index` / `sharedindex.*`.

## Findings

### Core format — gitformat-index

- **URL:** https://git-scm.com/docs/gitformat-index
- **Path:** `$GIT_DIR/index` (also split-index `sharedindex.*` per layout)
- **Header:** signature `DIRC`, version **2, 3, or 4**, 32-bit entry count.
- Hash algorithm for checksums/OIDs follows repository SHA-1 vs SHA-256.
- **Entries:** sorted by path as unsigned bytes (`memcmp` order); same name sorted by stage; fields include ctime/mtime/dev/ino/mode/uid/gid/size/OID/flags/path (v4 path compression differs).
- **Extensions:** 4-byte signature + 32-bit size + data; if first byte is `A`–`Z`, extension is **optional** and may be ignored when unknown.
- Trailing hash checksum over content before the checksum.

### Documented extensions (names from gitformat-index)

Exact byte layouts are on the man page; catalog of why they matter:

| Extension (common names) | Role | Compat note |
|--------------------------|------|-------------|
| Tree / cache-tree | Cached tree OIDs matching index regions | Speed; must be invalidated correctly |
| Resolve undo | Conflict undo data | Merge interop |
| Link / split index | Points at shared index | Must understand or refuse split repos |
| UNTR / untracked cache | Cached untracked dir info | Optional |
| FSMN / fsmonitor | FS monitor cookie | Optional; platform-specific |
| Sparse index related | Directory entries with mode `040000`, `SKIP_WORKTREE`, trailing `/` when sparse cone + sparse index enabled | Must not expand incorrectly |

### Sparse index — technical

- **URL:** https://git-scm.com/docs/sparse-index
- Works with sparse-checkout cone mode and index extension machinery described in gitformat-index.
- **Compat impact:** GIR must either implement sparse index semantics or avoid writing sparse indexes / clear the extension when rewriting.

### Racy-git

- **URL:** https://git-scm.com/docs/racy-git
- Documents mtime/size races between worktree and index.
- **Compat impact:** performance optimizations must not break racy-git detection expectations when sharing an index with stock Git.

### Parallel checkout

- **URL:** https://git-scm.com/docs/parallel-checkout
- Worker protocol for checkout; optional. Not required to read foreign indexes.
