# arks perf beyond M17

Design research for **Phase Pf4 / M18** — aggressive comparative timing uplift **after** M17 full G19 exit (19/19 ≤0.8×, N/A-free). Normative bars live in [[sot:root/program-roadmap]] and [[plan:root/20261109125438]]. This note records empirical hotspots, opportunity classes, and primary cites — **no invented Git semantics**.

## Question

Where does wall-clock still leave material headroom versus stock Git on the current G16/G19 catalog after M17, and which opportunity classes justify a Pf4 engineering wave without redefining M14/M17 historical exits?

## Method

1. Take authoritative M17 exit receipt [[evidence:root/20261109090000]] (`median_p95`, release, Docker `g019-comparative-performance`) as the **before** baseline.
2. Rank journeys by **ratio proximity to 0.8×** and by **absolute arks wall-ms** (edge + heavy).
3. Drill step-level metrics for DIFF / ARCHIVE / LOCAL / ADD-heavy paths.
4. Cross-walk PERF-class concurrency catalog rows ([[sot:root/multi-agent-git-concurrency-scenarios]], [[research:root/20261109023117]]) for process-tax / lock / status themes — observability for Pf4, not a G17/G18 reopen.
5. Cite primary Git docs only where on-disk or porcelain semantics constrain the optimization.

## Opportunity classes (Pf4)

| Rank | Class | Evidence / catalog | Pf4 action | Semantic constraint |
|-----:|-------|--------------------|------------|---------------------|
| 1 | **Stdout / syscall tax on bulk porcelain** | DIFF `diff --cached` 23 vs 12; many `println!` per hunk | `BufWriter` + batched `write!` for diff/archive emitters | Output bytes MUST remain unified-diff / ustar compatible ([git-diff](https://git-scm.com/docs/git-diff), [git-archive](https://git-scm.com/docs/git-archive)) |
| 2 | **Index path O(n) updates on bulk `add`** | DIFF `add -A` 32 vs 27; per-path `retain`/`find` | HashMap stage-0 lookup + single retain/extend | Index v2 bytes + lockfile ([gitformat-index](https://git-scm.com/docs/gitformat-index), [api-lockfile](https://git-scm.com/docs/api-lockfile)); lease ≠ skip locks |
| 3 | **Untracked walk sort amplification** | `collect_untracked` sorted on every recurse | Sort once at top level | Path listing order does not change OID identity |
| 4 | **Archive tree flatten + loose/pack reads** | ARCHIVE 0.75× | Buffered file write; keep streaming ustar (no full RAM buffer) | ustar claimed subset; [git-archive](https://git-scm.com/docs/git-archive) |
| 5 | **Process-per-command tax** | PERF-006 / AGENT-003; short journeys at 2–6 ms quantum | Release profile already thin-LTO; prefer amortizing seeds (M17) over semantic skip; no in-process multi-command daemon in Pf4-1 | Native engine ADR; zero-gix |
| 6 | **Status / full-tree walk** | PERF-002 | Already have `ce_match_stat`-class short-circuit ([[research:root/20261108071915]]); extend only where measured | racy-git honesty; do not invent fsmonitor dialect |
| 7 | **Lock contention (multi-agent)** | IDX-001 / PERF-001 | Out of Pf4 timing bar — G17/G18 already closed claimed sets; do **not** skip exclusive locks | [[sot:root/lease-concurrency-intent]] |
| 8 | **Pack / clone / repack** | CLONE / REPACK already ≤0.55× | Regression-only in Pf4-1 | pack format cites [[research:root/20261108071913]] |

## Non-goals / fail-closed

- Redefining M14 frozen allow-list or M17 ≤0.8× exit receipts.
- Host-only SLOs as verified.
- Skipping Git locks / inventing lock dialects (lease ≠ skip).
- CELIR / `gix` / L3 N-way as perf shortcuts.
- Concurrent Docker G19 (OOM / exit 137) — one `g019-comparative-performance` at a time.
- G8 live remote as perf oracle (Closed-deferred).
