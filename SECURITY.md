# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities **privately** via GitHub Security Advisories for this repository:

https://github.com/modootoday/arks/security/advisories/new

Do **not** open a public issue for security reports.

When reporting, include enough detail to reproduce the issue. Do **not** include secrets, credentials, private keys, tokens, or unredacted private evidence beyond what is strictly needed to demonstrate the vulnerability.

## Supported Versions

This project is pre-1.0 (workspace version `0.0.0`). Until a stable release policy is published, security fixes apply to the default branch (`main`) only.
